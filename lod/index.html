Level of development, element by element

"LOD 300" alone says almost nothing. For each kind of element, this page lists what must be drawn in 3D and which data it must carry at each level, and which BIM uses need it. A BEP or contract can point to these rows, and a model checker can test them.

Each level adds to the one before. Geometry and data are listed separately because they mature at different speeds: a door can be placed exactly (geometry at LOD 300) long before its hardware set is known.

LOD 500 means checked in the field after construction, to a stated accuracy. It is not more detail than LOD 400, and it is never assumed: the owner asks for it, pays for it and says who surveys.

All wording on this page is OpenBEP's own. The levels are organised like the BIMForum LOD Specification, which may be cited but not copied; clearance zones and connectors follow good practice in manufacturers' object guides such as the bimstore Bible. Parameter names come from IFC 4.3 property sets and COBie fields; Revit names are built-in parameter names, to verify for each Revit version. Which BIM use needs which requirement is our own judgement, still to be validated with practitioners. Text: CC BY 4.0.
